Brief

What did you eat last night?

    MODULE 04 :: HANDS-ON

    Three steps over one file.

    The same 20-company snapshot in two tools: clean the rows and chart the yield in Sheets, then filter the same rows in Colab. You leave with two files.

    1. STEP 01 :: SHEETS

      Clean the rows.

      • One file, demo_company_metrics.csv: 20 familiar names and three metric columns.
      • Fix the formats, then keep only complete rows; 20 rows become 17.
      • Missing stays missing: a blank yield is never zero.

    2. STEP 02 :: SHEETS

      Chart the yield.

      • Sort the complete rows by yield, largest first.
      • Chart yield for 5 to 7 familiar names.
      • Write one sentence about what the chart shows.

      LEAVES :: SHEET TAB + CHART + INSIGHT

    3. STEP 03 :: COLAB

      Filter in code.

      • Load and peek: df = pd.read_csv("demo_company_metrics.csv").
      • Mask, then sort: keep complete rows and rank by yield.
      • Change the rule, change the table.

      LEAVES :: SHORTLIST + RULE + CAVEAT

    THREE WORDS

    ticker
    shorthand for a company.
    yield%
    cash divided by price.
    blank
    missing, never zero.
