The data science life cycle

Pre-work for the UPSkill 1S2627 applicants workshop. Walk the seven stages, read what the hands-on asks of you, and bring one question. About six minutes.

BRIEF :: WARM-UP

Brief

What did you eat last night?

That answer is data. What you ate, when, and what it cost all left records: receipts, app orders, messages, a bank line. The workshop opens by asking what data you already produce without noticing.

PHASE 01 :: DEFINE

Start with the problem, not the data.

  • Understand how data science applies to the domain.
  • Data scientists and domain experts frame it together.
  • Weigh resources, value, risks, and ethical concerns.

STAGE 01 / 07

PHASE 01 :: DEFINE

Collect what the problem needs.

  • Structured data: customer records, tables, transactions.
  • Unstructured data: video, images, and audio.
  • Collected by manual entry, scraping, or live streams.

STAGE 02 / 07

PHASE 02 :: BUILD

Clean it before you store it.

  • Set standards for storing and structuring data.
  • Clean and transform with ETL: extract, transform, load.
  • Data preparation ensures quality before storage.

STAGE 03 / 07

PHASE 02 :: BUILD

Let the data speak.

  • Apply machine learning algorithms and statistical models.
  • Predict, classify, and reveal hidden patterns.
  • Insights must serve the goal of the project.

STAGE 04 / 07

PHASE 02 :: BUILD

Choose the model that fits.

  • Select a model type that matches the problem.
  • Choose algorithms that extract insight effectively.
  • Prevent overfitting: perform on train and test data.

STAGE 05 / 07

PHASE 03 :: DELIVER

Put the model to work.

  • Create the delivery mechanism that carries the model.
  • Make it accessible to users, applications, and systems.
  • Deploy anywhere from dashboards to cloud environments.

STAGE 06 / 07

PHASE 03 :: DELIVER

Make the insight land.

  • Present findings in simple language and visuals.
  • Design for stakeholders without technical backgrounds.
  • The goal: informed decisions, not just charts.

    MODULE 04 :: HANDS-ON

    What the workshop asks of you.

    Two passes over the same file. In Sheets you clean it and chart it; in Colab you filter the same rows with code. You leave with two files and one honest caveat.

    PASS 01 :: SHEETS

    Clean it, keep complete rows, chart yield.

    • One file, demo_company_metrics.csv: 20 familiar names and three metric columns (last_price, div_yield_pct, data_complete).
    • Fix the formats, then keep only complete rows; 20 rows become 17.
    • Sort, chart yield for 5 to 7 familiar names, and write one sentence.

    PASS 02 :: COLAB

    The same CSV, in code.

    • Load and peek, then count the blanks.
    • Mask, then sort: keep complete rows and rank by yield.
    • Change the rule, change the table.

    df = pd.read_csv("demo_company_metrics.csv")
